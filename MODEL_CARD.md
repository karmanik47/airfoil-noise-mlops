# Model Card: Airfoil Noise Random Forest

## Общая информация

- Тип задачи: регрессия
- Модель: `RandomForestRegressor`
- Библиотека: scikit-learn
- Версия preprocessing: `v1`
- Версия релиза: `v1.0.0`
- Целевая переменная: `scaled_sound_pressure`
- Единица результата: дБ

Модель прогнозирует уровень звукового давления авиационного профиля по пяти аэродинамическим параметрам.

## Назначение

Модель предназначена для:

- учебной демонстрации полного MLOps-процесса;
- оценки уровня аэродинамического шума внутри области исходных данных;
- использования через HTTP API и интерфейс Streamlit;
- воспроизводимого сравнения моделей регрессии.

Модель не предназначена для сертификационных, промышленных или критичных для безопасности расчётов.

## Входные данные

| Признак | Тип | Единица |
|---|---|---|
| `frequency` | float | Гц |
| `angle_of_attack` | float | градусы |
| `chord_length` | float | м |
| `free_stream_velocity` | float | м/с |
| `suction_side_displacement_thickness` | float | м |

API проверяет, что физические величины не имеют недопустимых отрицательных или нулевых значений.

Порядок признаков загружается из `models/metadata.json`, поэтому он совпадает с порядком признаков при обучении.
