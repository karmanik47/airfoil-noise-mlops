# Airfoil Noise MLOps

Воспроизводимый MLOps-проект для прогнозирования уровня аэродинамического шума авиационного профиля.

## Задача

По пяти аэродинамическим параметрам модель прогнозирует уровень звукового давления в децибелах.

## Данные

Используется датасет NASA Airfoil Self-Noise из UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/291/airfoil+self+noise

## Планируемые компоненты

- воспроизводимая подготовка и версионирование данных;
- учёт ML-экспериментов;
- обучение и выбор модели регрессии;
- HTTP API на FastAPI;
- автоматические тесты;
- запуск в Docker;
- пользовательский интерфейс на Streamlit.

## Статус

Проект находится в разработке.
