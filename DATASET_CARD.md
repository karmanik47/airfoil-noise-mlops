# Dataset Card: NASA Airfoil Self-Noise

## Общая информация

- Название: NASA Airfoil Self-Noise
- Задача: регрессия
- Количество наблюдений: 1503
- Количество исходных признаков: 5
- Целевая переменная: уровень звукового давления, дБ
- Источник: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/291/airfoil+self+noise)
- DOI: [10.24432/C5VW2C](https://doi.org/10.24432/C5VW2C)
- Авторы: Thomas Brooks, D. Pope, Michael Marcolini
- Лицензия: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

Данные были получены NASA в ходе аэродинамических и акустических испытаний двухмерных и трёхмерных секций авиационных профилей в безэховой аэродинамической трубе.

## Назначение

Датасет используется для обучения регрессионной модели, которая прогнозирует масштабированный уровень звукового давления по параметрам авиационного профиля и воздушного потока.

Датасет не содержит персональных данных.

## Состав данных

| Поле | Роль | Единица измерения | Наблюдаемый диапазон |
|---|---|---|---:|
| `frequency` | Признак | Гц | 200–20000 |
| `angle_of_attack` | Признак | градусы | 0–22.2 |
| `chord_length` | Признак | м | 0.0254–0.3048 |
| `free_stream_velocity` | Признак | м/с | 31.7–71.3 |
| `suction_side_displacement_thickness` | Признак | м | 0.000401–0.058411 |
| `scaled_sound_pressure` | Целевая переменная | дБ | 103.380–140.987 |

В исходном файле нет заголовка. Названия столбцов назначаются в коде подготовки данных.
